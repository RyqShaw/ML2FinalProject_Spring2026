# Game Player Retention Analysis
By Sharyq Siddiqi, Leyuan Wang, Nathan Moeykens

## Description
Using Three Different Machine Learning Models, our goal is to build a tool for prediction of a Online Games Player Retention, and see the attributes that contribute to maintaing an active playerbase. This would be used with the intention of helping build games that players would like to stick with rather. We plan to go with 3 Different Models, in Bayesian, Traditional MLP neural Networks, and Time Series(To be determined based on accessible data.
